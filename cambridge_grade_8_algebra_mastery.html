Terminology & Like Terms

An algebraic expression combines numbers, variables (letters), and operation symbols. Click the expression parts below to explore their definitions:

1. Variable

A letter representing an unknown or changing value (e.g., $x, y, a$).

2. Coefficient

The numerical multiplier in front of a variable (e.g., in $5x$, 5 is the coefficient).

3. Constant

A fixed numerical value without any attached variable.

4. Term

Parts of an algebraic expression separated by $+$ or $-$ signs.

Golden Rule: Like Terms vs. Unlike Terms

✅ Like Terms (Can Combine)

Must have the exact same variables AND exact same powers.

$3x$ and $-7x$ • $5a^2b$ and $2a^2b$

❌ Unlike Terms (Cannot Combine)

Different variables OR different powers.

$4x$ and $4y$ • $3x^2$ and $3x^3$

Addition & Subtraction of Algebra

BRACKET EXPANSION RULE FOR SUBTRACTION:

When a minus sign precedes a set of brackets, you must distribute the negative sign to every term inside the brackets!
$$\text{Example: } -(4x - 3y + 5) = -4x + 3y - 5$$

Example 1 (Addition)

Simplify: $(5x - 2y + 4) + (3x + 6y - 7)$

  1. Group like terms:
    $$= (5x + 3x) + (-2y + 6y) + (4 - 7)$$
  2. Simplify coefficients:
    $$= 8x + 4y - 3$$
Example 2 (Subtraction)

Simplify: $(7x + 3y - 5) - (2x - 4y + 3)$

  1. Distribute the minus sign:
    $$= 7x + 3y - 5 - 2x + 4y - 3$$
  2. Group & combine:
    $$= (7x - 2x) + (3y + 4y) + (-5 - 3)$$
    $$= 5x + 7y - 8$$

Multiplication & Expanding Brackets (Binomials & Quadratics)

Multiplying variables with the same base adds their exponents ($x^a \times x^b = x^{a+b}$). Expanding brackets uses the distributive law ($a(b + c) = ab + ac$) and FOIL/quadratic multiplication methods.

Single & Combined

Expand: $3x(2x - 5) + 4(x^2 + 3x)$

  1. Multiply $3x$ into $(2x - 5)$: $6x^2 - 15x$
  2. Multiply $4$ into $(x^2 + 3x)$: $4x^2 + 12x$
  3. Combine: $6x^2 - 15x + 4x^2 + 12x$
  4. Result: $10x^2 - 3x$
Binomial Expansion (FOIL)

Expand: $(x + 3)(x + 5)$

  1. First: $x \times x = x^2$
  2. Outer: $x \times 5 = 5x$
  3. Inner: $3 \times x = 3x$
  4. Last: $3 \times 5 = 15$
  5. Combine: $x^2 + 5x + 3x + 15$
  6. Simplified: $x^2 + 8x + 15$
Quadratic / Difference of Squares

Expand: $(2x - 3)(2x + 3)$

  1. First: $2x \times 2x = 4x^2$
  2. Outer: $2x \times 3 = 6x$
  3. Inner: $-3 \times 2x = -6x$
  4. Last: $-3 \times 3 = -9$
  5. Combine: $4x^2 + 6x - 6x - 9$
  6. Result: $4x^2 - 9$ (Difference of Two Squares!)

Division of Algebraic Expressions (Multiple Types)

Algebraic division is performed by dividing coefficients and subtracting exponents of like variables ($\frac{x^a}{x^b} = x^{a-b}$). Below are three distinct types of algebraic division commonly tested in Cambridge Grade 8.

Type A: Binomial by Monomial

Simplify: $\frac{12x^3 - 8x^2}{4x}$

1. Split into separate fractions: $\frac{12x^3}{4x} - \frac{8x^2}{4x}$

2. Divide coefficients & subtract powers: $3x^{3-1} - 2x^{2-1}$

Result: $3x^2 - 2x$

Type B: Higher Powers & Negatives

Simplify: $\frac{-18x^4 + 12x^3}{6x^2}$

1. Split terms: $\frac{-18x^4}{6x^2} + \frac{12x^3}{6x^2}$

2. Compute: $-3x^{4-2} + 2x^{3-2}$

Result: $-3x^2 + 2x$

Type C: Multi-Variable Division

Simplify: $\frac{24a^3b^2 - 16a^2b^4}{8ab^2}$

1. Split terms: $\frac{24a^3b^2}{8ab^2} - \frac{16a^2b^4}{8ab^2}$

2. Apply index laws: $3a^{3-1}b^{2-2} - 2a^{2-1}b^{4-2}$

Result: $3a^2 - 2ab^2$

Part 4: Equations & Balance Method

Linear Equations & Solving Techniques

Expressions vs. Equations:

An Algebraic Expression does not have an equals sign (e.g., $3x + 5$). An Equation contains an equals sign ($=$) and states that two expressions are equal (e.g., $3x + 5 = 17$).

Worked Examples on Solving Equations:

Type 1: Two-Step Equation

Solve: $4x - 7 = 13$

1. Add 7 to both sides: $4x = 13 + 7 \implies 4x = 20$

2. Divide both sides by 4: $x = \frac{20}{4}$

Answer: $x = 5$

Type 2: Equations with Brackets

Solve: $3(2x + 4) = 24$

1. Expand brackets: $6x + 12 = 24$

2. Subtract 12 from both sides: $6x = 12$

3. Divide by 6: $x = 2$

Answer: $x = 2$

Type 3: Unknowns on Both Sides

Solve: $5x - 3 = 2x + 12$

1. Subtract $2x$ from both sides: $3x - 3 = 12$

2. Add 3 to both sides: $3x = 15$

3. Divide by 3: $x = 5$

Answer: $x = 5$

Type 4: Word Problem

"Three times a number plus 7 gives 28. What is the number?"

1. Let the unknown number be $x$. Form equation: $3x + 7 = 28$

2. Subtract 7: $3x = 21$

3. Divide by 3: $x = 7$

Answer: The number is $7$.
